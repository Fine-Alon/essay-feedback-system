Why For ?

The Target Audience

Data Flow & Database

Local File System

Instead of using a heavy relational database for our MVP, we moved for a lightweight and reliable approach. By using Python's built in lib to perform CRUD operations, saving user profiles, essays, and reports directly as JSON files.

Auth & Client State

Authentication: once the server validates the login credentials, the frontend browser stores the User ID in memory (Client-Side State Management). This allows us to securely attach all uploaded essays to the correct author during the session.

Technical Challenges & Solutions

Payload Management

Challenge: Sending a physical .txt file alongside text data to the backend.

Solution: We utilized the built-in FormData object in JavaScript to package the payload as multipart/form-data. On the backend, we configured FastAPI to intercept this using the Form(...) dependency, successfully bridging the gap between client and server.

UI/UX Synchronization

Challenge: Users had to manually copy their generated Essay ID and paste it to get a report.

Solution: We built an auto-fill mechanism. Upon successful upload, the frontend intercepts the ID, injects it directly into the "Get Report" input field, and triggers a subtle CSS box-shadow animation to visually guide the user's attention.
